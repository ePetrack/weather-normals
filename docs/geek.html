    Data via the ACIS Web Services API, the same source behind the NWS's NOWData tool. Degree days are computed live in your browser from each day's high and low: mean = (high + low) / 2, HDD = max(0, base − mean), CDD = max(0, mean − base). Normal degree days are derived from the 1991–2020 daily normal highs and lows, so they differ slightly from NOAA's published degree-day normals; the monthly charts use NOAA's published base-65°F normals when available. Days with a missing high or low are skipped. Updated automatically every day via GitHub Actions — source on GitHub.
