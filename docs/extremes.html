Precipitation Extremes

Is rain arriving in fewer, bigger events or more frequent small ones? Eight views of the same 35 years of daily precipitation, each looking for the same signal from a different angle.

Normals Extremes

Horizon chart

One folded-color band per year (oldest at top, this year at bottom). Darker cells are wetter days — scan down the stack for the recent rows looking "hotter" than the older ones.

Calendar heatmap

Every day since 1991, colored by rainfall intensity — years as rows, day-of-year as columns.

Storm counts by size

Each dot is one storm (a run of consecutive wet days), stacked by size — normal-period average vs. recent average vs. this year, so you can compare event counts directly instead of reading a smoothed histogram.

Monthly precipitation range

Candle body = the historical 10th–90th percentile range for that month (1991–present); whiskers = the all-time min/max. The marker is this year's total — red if it busts outside the normal range.

Storm events over time

One candle per storm of at least 1″ total rainfall, across the full record. Bar height = total rainfall; the notch marks the single wettest day within the storm.

Rainfall by intensity, year over year

Each year's total rainfall split by how it fell — trace, light, moderate, heavy, extreme days. Watch whether the "heavy"/"extreme" band is thickening at the expense of "light."

Year rings

A compact radial calendar per year: each spoke is one rainy day (angle = day of year, length and color = rainfall amount, same intensity scale as the calendar heatmap above). Thin lines mark the Mar 1 / Jun 1 / Sep 1 / Dec 1 season boundaries. The thin inner ring is split into 5 season arcs colored by that season's ENSO phase, from NOAA CPC's Oceanic Niño Index — a ring with more than one color means the phase flipped mid-year, and a fainter arc means a weaker event (hover a segment for the exact ONI value). Dashed outline = not yet known (current year).

Rain bubble strip

One row per year; a bubble marks every wet day, sized by that day's rainfall. A row of many small bubbles tells a different story than a row with a few huge ones.

Data via the ACIS Web Services API, the same source behind the NWS's NOWData tool. "Storm" events are runs of consecutive days with measurable precipitation; a single missing day inside a run is bridged, two or more ends it. Updated automatically every day via GitHub Actions — source on GitHub.
